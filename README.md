ADD NEW RECORDS UPGRADE
For the working editable college dashboard previously supplied.
1. Stop Flask with Ctrl+C.
2. Extract add_records_upgrade.py into the same folder as your working app.py.
3. Run .\.venv\Scripts\python.exe add_records_upgrade.py
4. Run .\.venv\Scripts\python.exe app.py
5. Refresh http://localhost:5000 and use Add new record in each table section.
No new dependencies. Keep .env unchanged. The installer backs up app.py and
index.html before patching them; it makes no database changes itself.
Back up/test your database before saving real records.
Student and course IDs must be entered manually and must be unused. Enrollment
IDs are generated by MySQL. Create students/courses before adding enrollments.
Your MySQL account needs INSERT as well as existing SELECT/UPDATE permissions.
Successful inserts redirect to the new record's Edit page, so you can verify it
even if its ID falls outside the dashboard's first 100 rows. Optional blanks
become NULL; dates are entered manually or left blank. Values are parameterized,
forms use existing CSRF protection, writes commit/rollback. No delete controls.
Keep localhost-only: no login or public deployment support is added.
Rollback application changes by copying backed-up app.py and index.html back
and restarting. This does NOT undo records you have already added to MySQL.
Validation errors preserve entered values. Duplicate enrollments are not blocked
unless your database defines a unique constraint for student_id/course_id.
Syntax/templates checked during generation; test with your real MySQL locally.
